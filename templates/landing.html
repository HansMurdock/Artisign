Frequently Asked Questions

Jawaban seputar aspek keamanan, privasi data, dan keabsahan tanda tangan.

Apa yang terjadi jika berkas digital diubah meski hanya 1 karakter atau 1 pixel? ↓

Fungsi hash SHA-256 memiliki sifat *Avalanche Effect*. Mengubah 1 bit data sekalipun akan menghasilkan 32-byte hash yang berbeda total. Saat diverifikasi dengan tanda tangan ECDSA, sistem secara matematis akan langsung menolak dokumen dan memberikan status DOKUMEN TIDAK VALID / TELAH DIMODIFIKASI.

Apakah berkas rahasia saya diunggah ke internet saat verifikasi? ↓

Tidak. Halaman Validator Artisign menggunakan teknologi Client-Side Hashing melalui Web Crypto API. Berkas Anda dianalisis secara lokal di dalam browser laptop/HP Anda. Hanya sidik jari hash (string 64 karakter) yang dicocokkan, sehingga privasi dan kerahasiaan isi berkas tetap 100% aman di perangkat Anda.

Bagaimana cara orang lain memverifikasi berkas saya? ↓

Sangat mudah! Mereka cukup mengarahkan kamera HP ke stempel QR Code di dokumen PDF Anda, atau mengunggah file sertifikat JSON / ZIP ke halaman Validator Publik. Sistem akan seketika mencocokkan kunci publik dan sidik jari dokumen.

Format file apa saja yang didukung oleh Artisign? ↓

Artisign mendukung seluruh jenis berkas digital (PDF, Dokumen DOCX, Gambar PNG/JPG, Video MP4, Model 3D FBX/OBJ, maupun Arsip ZIP). Khusus dokumen PDF, sistem menyediakan fitur tambahan stempel visual QR code langsung pada lembar dokumen.
